# 悬浮自动点击器 (Auto Clicker 2.0)

一个基于 Python + tkinter + Win32 API 的 Windows 悬浮自动点击器，专为**指定窗口内自动点击**设计。

## 特性

- **窗口锁定** — 绑定窗口句柄（HWND）而非标题，窗口标题变化也能持续识别
- **两种注入方式**
  - 物理点击：移动真实鼠标并在目标处点击
  - 后台注入：直接向目标窗口 `PostMessage` 鼠标消息，**不占用鼠标、不影响你同时干别的事**
- **三种点击定位**
  - 窗口内随机（避免固定位置）
  - 窗口中心
  - 手动拾取坐标（鼠标点哪儿就是哪儿）
- **灵活的点击参数** — 单击 / 长按、左/中/右键、点击次数、按住时长、点击间隔
- **全局热键**
  - `Ctrl + Alt + PageUp` — 开始
  - `Ctrl + Alt + PageDown` — 紧急终止
- **现代化 UI** — 圆角深色界面、抗锯齿绘制、缓动动画、实时进度条

## 运行环境

- Windows 10 / 11
- Python 3.8+（推荐 3.10+）
- 依赖：`pillow`（可选，缺少时退化为平滑多边形绘制，效果略降）

```bash
pip install pillow
python clicker.py
```

## 打包为 EXE

```bash
pip install pyinstaller
pyinstaller -F -w clicker.py
```

## 直接使用

仓库内的 `clicker.exe` 为已打包版本，双击即用，无需 Python 环境。

## 使用步骤

1. 打开「目标窗口」下拉框，选中要点击的窗口（可点「刷新」重扫）
2. 选择注入方式、点击方式、鼠标按键，填好次数/时长/间隔
3. 选择点击位置（随机 / 中心 / 拾取）
4. 点「开始」，或按 `Ctrl + Alt + PageUp`
5. 需要中断时，按 `Ctrl + Alt + PageDown` 紧急终止

## 说明

- 「后台注入」模式下点击事件直接发给目标窗口，适合在窗口最小化或被遮挡时继续工作
- 目标窗口关闭时会自动停止并提示
- 请仅用于你自己的程序与合法用途
